How it works

The sparkle is a constant alpha composite, so it is invertible:

observed = (1 − a·m)·original + a·m·white

Solving for original recovers the true pixels instead of smearing them like inpainting does. Everything runs on the yuv420p planes, so only the 76×76 patch is ever touched — the rest of the frame stays bit-identical until the final encode.
